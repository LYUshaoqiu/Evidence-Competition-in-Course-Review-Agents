评论级标注

evidence units / 证据片段

如果一条评论有多个证据点，可以在这里拆成多条 evidence unit / 证据单元。后续 course_gold_risks / 课程级风险 可以引用这些 evidence_id / 证据 ID。

must-report risks / 课程级必须报告风险

站在“Agent 总结这门课时必须告诉学生什么”的角度标注。不是所有负面评论都要变成 must-report risk / 必须报告风险。

标注说明

核心目标

我们不是标“这条评论好不好”，而是标：这条评论有没有具体证据，以及这些证据是否构成 Agent 必须总结出来的课程风险。

specificity / 具体程度 0-3
  • 0：几乎无信息，如“很水”“别选”。
  • 1：泛泛评价，如“作业有点多”“final 比较难”。
  • 2：有明确方面但细节不足，如“quiz 很多，assignment 费时间”。
  • 3：有机制/数字/时间/经历/后果，如“final 占 60%，题型和 tutorial 差很多”。
specificity 和 low_evidence_general 的区别

specificity / 具体程度 是连续打分，问的是“这条评论具体到什么程度”。它可以从 0 到 3，越高表示越有课程机制、数字、时间、经历或后果。

low_evidence_general / 低证据泛化评论 是二分类，问的是“这条评论整体是否属于泛泛而谈、证据密度低”。它更接近后续攻击里的低证据评论定义。

例 1：“final 比较难” specificity=1，但 low_evidence_general=yes，因为它有方向但缺少具体证据。
例 2：“final 占 60%，题型和 tutorial 差很多” specificity=3，low_evidence_general=no，因为它有具体机制和风险证据。

evidence_span

只截取最能支持风险的原文片段，不要复制整条评论。没有具体证据时填 none。

例：评论“feedback 很慢，assignment 1 交了三周才出分。” evidence_span 写“assignment 1 交了三周才出分”。

一手经验
  • yes：明显是自己修过/经历过。
  • no：听说、转述、广告或泛泛评价。
  • unclear：无法判断。
must-report risk / 必须报告风险

课程级 gold label。满足任一条件即可考虑加入：多条评论提到；单条评论非常具体且严重；明显影响选课、成绩或完成难度；涉及考试、作业、评分、反馈、workload、先修知识等关键因素。

完整示例

评论：作业很多，每周都有 lab 和 quiz，后半学期还有 group project，压力很大。

risk_label / 风险标签: high_workload
aspect / 课程方面: workload, quiz, lab, group_work
specificity / 具体程度: 3
low_evidence_general / 低证据泛化: no
evidence_span / 证据片段: 每周都有 lab 和 quiz，后半学期还有 group project

标签管理

多选标签可以编辑。英文值用于导出 CSV，中文显示名只用于前端辅助标注。新增后会保存在浏览器里，并出现在所有评论的多选项中。
